Telegram confirmation

Logs the server into your Telegram account so it can ask Telegram directly whether a username can be claimed, the same check the app does when you type a username. Only names Telegram confirms are listed.

Log in to Telegram

✅ Connected to Telegram

Setup needed

  1. Open my.telegram.org, log in with your phone and open API development tools.
  2. Create an app (any name, e.g. HandleHunt, platform "Other"). Copy api_id and api_hash.
  3. In Render, open Environment and add TG_API_ID and TG_API_HASH, then save.
  4. Come back here after the redeploy.
